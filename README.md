# 📐 unit-converter

Uzunluk, ağırlık, sıcaklık, alan, hacim ve hız birimi dönüştürücü.

## Kurulum
```bash
cargo build --release
```
## Kullanım
```bash
unit-converter 100 km mi
unit-converter 72 F C
unit-converter 5 kg lb
```
